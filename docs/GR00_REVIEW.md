# GR00 官方文档核对

2026-10-17，从官网公开下载中心资料条目52取得 GR00 原理图/PIN脚/规格说明书包，外层ZIP 3956431字节，内部RAR只读解析。未执行厂商代码，资料未提交到仓库。

目录标签是 V1.0，但包内 `GR00模块说明书.pdf` 正文标题为 **GR00用户手册V1.1**，共4页，应以正文版本记录。第3页将 SBUS输出和串口透传分开：天空端UART2_TX / pin6为SBUS-TX；UART3_RX / pin29为透传RX，UART3_TX / pin27为透传TX。UART0是调试口，不应误用为控制透传口。

第4页给出模块5V供电，并说明此为需自行设计底板的集成模块。**模块供电值不能证明UART逻辑电平可直接接5V**；实际底板、飞控接口电平和保护设计尚未核实，不能据这些针脚说明自动接线或发送。

资料包另含 GR00原理图-20260324.pdf、G12-RX/GR01原理图及AD封装库。本阶段未完成原理图电气审查，不把GR01与GR00作为等同硬件。下一步须只读取得实际模块/底板型号和版本，核对电气接口，再做经授权的隔离台架验证。
