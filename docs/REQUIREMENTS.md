# 需求与验收边界

来源：2026-10-17 用户委托及其明确复述的原会话需求。没有假定历史代码存在或曾验收。

| ID | 要求 | 当前实现/边界 |
|---|---|---|
| R1 | G12 Android + 云卓 SDK，真实摇杆 | Android 模拟应用；官方SDK1.9.2已核对，只读类隔离，真实输入许可/语义待确认 |
| R2 | GR00 串口数传发送 MAVLink 至 X9 4.7.1 | 编解码在内存验证；真实传输阻塞 |
| R3 | 主 SBUS 保持 RC，串口双向数据；备用串口控制 | 架构保留；不增加第二 SBUS |
| R4 | 输入新鲜度、失联/生命周期停止 | 单调时钟，过期锁存停止，恢复后须显式重新开始 |
| R5 | 防重复接管与受控交还 | 单实例租约、会话代次、重复请求拒绝；跨设备仲裁尚未解决 |
| R6 | 安全默认 | 启动 READ_ONLY，显式进入模拟；不能启用硬件模式 |
| R7 | 目标身份校验 | 指定 sysid/compid + ArduPilot 四旋翼 HEARTBEAT + 固件版本 + UID；仍非密码学认证 |
| R8 | 保留围栏、安全检查、failsafe | 不写参数、不解锁、不切模式、不刷固件；不发送 GCS 心跳 |

本阶段验收仅覆盖离线代码、模拟状态和 APK 构建。不得据此签署真机/飞行验收。期望 X9 UID、GR00 接线/电平/波特率、实际 G12 Android/ABI、SDK 授权、接管开关和主机健康证据均待确定。
