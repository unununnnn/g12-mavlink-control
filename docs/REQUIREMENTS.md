# 需求与验收边界

来源：2026-10-17 用户委托及其明确复述的原会话需求。没有假定历史代码存在或曾验收。

| ID | 要求 | 当前实现/边界 |
|---|---|---|
| R1 | G12 Android + 云卓 SDK，真实摇杆 | 独立bench接入官方SDK1.9.2；用户自报只读成功，非独立硬件验收；输入源端新鲜度待确认 |
| R2 | GR00 串口数传发送 MAVLink 至 X9 4.7.1 | sender已实现真实G12数据管道/映射/显式启停，首先限定GR00 UART接电脑逐帧回显；发送版硬件未测，X9闭环仍待受控台架 |
| R3 | 主 SBUS 保持 RC，串口双向数据；备用串口控制 | 架构保留；不增加第二 SBUS |
| R4 | 输入新鲜度、失联/生命周期停止 | 单调时钟，过期锁存停止，恢复后须显式重新开始 |
| R5 | 防重复接管与受控交还 | 应用单实例门控；另有统一权威原型/跨进程测试；真实拓扑的强制排他仍待部署 |
| R6 | 安全默认 | 旧app只模拟，bench只读，sender默认停止且须明确确认电脑隔离后启停；sender发送真实#69/#70，不能用于飞行；无解锁/模式/参数写入入口 |
| R7 | 目标身份校验 | 指定 sysid/compid + ArduPilot 四旋翼 HEARTBEAT + 固件版本 + UID；仍非密码学认证 |
| R8 | 保留围栏、安全检查、failsafe | 不写参数、不解锁、不切模式、不刷固件；不发送 GCS 心跳 |

本阶段验收覆盖离线代码、模拟状态、APK构建和隔离disarmed SITL。不得据此签署真机/飞行验收。G12已知Android13，仍缺具体构建/ABI实测；X9 UID、GR00接线/电平/波特率、接管开关和主机健康证据仍待确定。SDK按官方集成指引用于本次私有台架开发，公开/商业分发范围另核实。实验仅允许改自启动SITL的SIM_RC_FAIL注入失效，其余安全参数读回比较，不改真实参数。
